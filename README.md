- Custom CSS with editorial / research-journal aesthetic

- Google Fonts: Fraunces, Inter Tight, JetBrains Mono

## Deploy

1. Create a public repo on GitHub named exactly `<your-username>.github.io`
2. Push `index.html` to the `main` branch
3. Go to **Settings → Pages → Source: `main` / root**
4. Wait ~1 minute. Site lives at `https://<your-username>.github.io`

## Local preview

```bash

python3 -m http.server 8000
# then open http://localhost:8000
```
